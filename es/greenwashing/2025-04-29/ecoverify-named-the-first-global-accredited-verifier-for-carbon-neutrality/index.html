EcoVerify named the first global accredited verifier for carbon neutrality

EcoVerify obtiene la acreditación global para verificar la neutralidad de carbono y las trayectorias hacia el cero neto. Este hito establece un nuevo estándar para validar las afirmaciones ambientales, combatiendo directamente el greenwashing mediante una rigurosa verificación por terceros.
