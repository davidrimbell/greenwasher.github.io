IESBA proposes draft ethics code to address greenwashing

IESBA proposes draft ethics code to address greenwashing

El IESBA ha propuesto nuevos marcos éticos para combatir el greenwashing, fortaleciendo la confianza en las divulgaciones corporativas sobre sostenibilidad. Estas normas responden a la creciente demanda de datos ESG confiables, con el objetivo de eliminar los sesgos y garantizar que las afirmaciones ambientales estén fundamentadas y sean transparentes. Al establecer directrices claras de conducta, la iniciativa busca elevar la calidad general de la información reportada. Estas propuestas coinciden con la aplicación de normativas europeas más estrictas contra las afirmaciones ambientales engañosas e involucran a partes interesadas a nivel mundial para asegurar su amplia aplicabilidad. El marco influirá en los organismos de acreditación de todo el mundo, obligándolos a utilizarlo para verificar las afirmaciones de sostenibilidad. Esta armonización es fundamental para mantener la credibilidad transfronteriza, ya que los mercados de capitales dependen cada vez más de métricas precisas de sostenibilidad para la toma de decisiones. En última instancia, este desarrollo aborda el núcleo del greenwashing al institucionalizar la ética en los procesos de aseguramiento. Empodera a inversores, consumidores y reguladores para exigir una mayor responsabilidad a las corporaciones. Al fomentar la confianza mediante rigurosos estándares éticos, el marco proporciona una defensa estructural contra el marketing engañoso, asegurando que las narrativas de sostenibilidad reflejen prácticas corporativas genuinas y no retórica superficial.
